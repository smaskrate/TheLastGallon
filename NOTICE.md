# Notices

* The package copies no game assets. The icons and world models of every
  item but the fermentation vessel are referenced by name from the
  installed Project Zomboid game (The Indie Stone) and are not
  redistributed (`docs/asset-audit.csv`). The vessel's icon
  (`media/textures/Item_TLG_Fermenter.png`) was drawn for the mod by
  `tools/make-icons.ps1`.
* The fermentation vessel's model and texture
  (`media/models_X/TLG/Fermenter.fbx`, `media/textures/TLG/Fermenter.png`)
  were supplied for this mod on 2026-11-02; the model file names Tripo
  Studio as the tool that generated it. They were generated under a
  commercial Tripo licence, which Tripo's published help pages say allows
  their distribution (`art-src/fermenter/PROVENANCE.md`).
* No external mods, libraries or Workshop content are bundled or required.
* Real-world references in the specification (R8–R13) informed abstract game
  rules only; no text or data from them is reproduced.
