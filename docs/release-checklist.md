## Open implementation items

* Adapters, placeable machines and UI for biodiesel, wood gas, biogas,
  propane cylinders and electrical networks (domains merged and tested).
* Automation wiring (rules exist in the domain; no adapter yet).
* "Prepare removal" admin command (`migrations.md`). Run 54 shows what it
  must cover: without the mod, the game drops its machines (with their
  batches) and its ethanol in containers when it loads the save (its other
  fluids not tried; run 55 the same). Until then the player guide and
  `migrations.md` say what is lost and what to use up first.
* Wood-gas and electric vehicle conversions (no shipped definitions).
* Mark the making stages (`makes`) of the biodiesel, biogas, wood retort
  and ash pit recipes with their machines; until then Abort counts every
  stage of them (D-023).
* The fermentation vessel carried: the mod puts it down before any Lua
  action that plays its own animation (run 99), since that animation
  replaces the carry pose. Walking, running, sprinting and sneaking keep
  it in both hands with the pose on (run 108). Crouched it has a pose of
  its own that holds it upright (run 113), and so has sprinting, crouched
  or not (run 117). Running still tilts the barrel with the runner's lean
  and swings it through the stride (the standing clip; run 117's
  pictures). Turning or colliding while sprinting is not run: the turn
  animation poses the chest instead of the sprint clip, so the barrel may
  not hold steady while it plays. Not covered and
  not run: animations the game starts without a Lua action (opening
  doors, shoving, emotes); multiplayer with the carry pose (a multiplayer
  client asks the server to put it down, as the vehicle entry does).
  Still missing: the supplied model's editable sources (a `.blend` file
  or the Tripo project; `art-src/fermenter/PROVENANCE.md`).
